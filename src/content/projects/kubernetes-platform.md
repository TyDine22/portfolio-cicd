## Overview

A multi-node Kubernetes environment built on Google Cloud Platform for learning and deploying cloud-native applications.

## Infrastructure

The platform consists of:

- One Kubernetes control-plane node
- Two worker nodes
- Containerd runtime
- Calico networking
- Persistent storage
- NGINX Ingress
- TLS certificates
- Istio service mesh

## What I worked on

I configured and managed the Kubernetes environment using infrastructure and DevOps tooling.

The cluster was used to deploy frontend applications, backend services and microservice workloads.

## What I learned

This project gave me practical experience with Kubernetes networking, storage, ingress, TLS, service discovery and cluster operations.
